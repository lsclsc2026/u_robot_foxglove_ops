# 范围与限制

## 快照含义

本仓库来自 2026-09-13 本地归档的 `foxglove_handoff_20260913`。它保存可找回的监控脚本、ROS 源码、权重与历史参考；不是从机器人重新导出的当前安装目录，也不是已在新设备验证过的统一发布版本。

此次发布只整理副本、中文文档、来源、许可和文件清单，未改变业务代码与参数默认值。按用户要求没有执行编译、功能测试、连接机器人或启停业务；只做发布需要的文件尺寸、敏感凭据与新增文档链接检查。

## 包含与不包含

包含 WSL 客户端、宿主机 Docker 入口、容器总控、图像中继、资源采集、可选 Vision/Nav 保护、新旧遥控实现、ROS 工作空间源文件、导航第三方源码和现有模型权重。

不包含厂商镜像、完整厂商 SDK/驱动、目标机挂载、全部现场地图、工作空间 build/install/log、SSH 私钥或账号密码、运行 PID/缓存、Git 历史。部分地图和仿真资源是源码包自己的测试/示例资产，不能当成目标现场地图。历史 tar.gz 重复副本未发布，详见[排除清单](provenance/excluded-files.tsv)。

## 已知差异

| 项目 | 本仓库应采用的解释 |
|---|---|
| VERSION | 当前监控文件仍是 `1.7.0`；历史材料有 `1.8.0`，不据此推断实机版本。Release `v0.1.0-review` 只标记本仓库整理版本 |
| Vision | 集成入口直接生成三相机配置并 `ros2 run`，绕过可选 launch 锁 |
| 互斥 | 总控 flock、源码 Vision 文件锁、optional 目录锁存在不同边界，尚未统一 |
| 遥控 | 当前 runner 调用 `mos_ops_control`；旧 `foxglove_teleop_guard.py` 仅保留历史实现，30 秒租约描述不适用 |
| teleop 启动集合 | `_common.sh` 仍含 navigation，入口会补启动缺失导航；ops 节点本身不启动第二套导航 |
| 日志 | 事件日志有上限，组件 stdout/stderr 和 ROS 日志没有同等限制 |
| 布局 | 只有占位 README，没有可导入 JSON；演示不自动还原 |
| 健康判断 | 进程/ROS 图存在不等于定位、控制、网络或硬件健康 |

`reference/`、代码树中的 dated docs、原始 README 和校验文件都保留其来源/日期含义。不同历史方案不能拼接成未经验证的新部署步骤。当前流程以仓库根 README 与本次 `docs/` 为入口，详细行为仍以对应代码为准。
