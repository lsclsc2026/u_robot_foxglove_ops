# Foxglove 标准布局

在 Foxglove 的布局菜单中将当前运维布局命名为 `MOS运维标准布局`，保存后使用布局菜单的
“导出”功能得到 JSON 文件。建议将文件命名为：

```text
MOS运维标准布局.json
```

把导出的 JSON 放在本目录即可随迁移包保存。新账号或新浏览器使用“从文件导入”恢复。
布局只保存面板结构和话题选择，不保存机器人的地图数据、实时消息或 SSH 密码。
