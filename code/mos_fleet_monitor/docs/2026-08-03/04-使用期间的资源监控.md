# 使用期间的资源监控

## 核心说明

当前可监控系统 CPU/负载/内存/磁盘/温度，Vision、导航、图像、状态脚本和 Bridge 的 CPU/RSS，
三路图像 FPS/帧龄，以及 ROS 2、传感器和导航链路状态。

```text
/mos/monitor/status_log       2秒一次核心摘要
/mos/monitor/diagnostics      2秒一次结构化详情
```

DDS 只保留最新 1 条，不写文件。

## 全部操作代码

单独启动：

```bash
source /opt/ros/humble/setup.zsh
source /tmp/mos_all_test_ws/install/setup.zsh
export ROS_DOMAIN_ID=111
export ROS_LOCALHOST_ONLY=1

python3 /root/work_space/mos_fleet_monitor/assets/mos_status_logger.py \
  --ros-args \
  -p interval_seconds:=2.0 \
  -p graph_interval_seconds:=10.0
```

读取状态：

```bash
ros2 topic echo /mos/monitor/status_log --once
ros2 topic echo /mos/monitor/diagnostics --once
```

总控启动时不需要再单独执行上述 Python 命令：

```bash
/home/lumos/mos_fleet_monitor/bin/mos-monitor-start
```

## 任务描述

输出 MOS 运行期间的系统和运维组件资源快照，用于判断 Foxglove 是否影响导航、Vision 和图像实时性。
