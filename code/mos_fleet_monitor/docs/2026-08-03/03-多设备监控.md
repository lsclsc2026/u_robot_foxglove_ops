# 多设备监控

## 核心说明

每台 MOS 的 Bridge 都使用容器内 8765，WSL 为不同机器分配不同本地端口。当前配置：

```text
mos-87   172.18.21.87    localhost:8765
mos-210  172.18.21.210   localhost:8766
```

## 全部操作代码

生成并分发 SSH 公钥：

```bash
ssh-keygen -t ed25519 -a 100 -f ~/.ssh/id_ed25519 \
  -C "mos-fleet-monitor"
ssh-copy-id -i ~/.ssh/id_ed25519.pub lumos@172.18.21.87
ssh-copy-id -i ~/.ssh/id_ed25519.pub lumos@172.18.21.210

ssh -o BatchMode=yes lumos@172.18.21.87 true
ssh -o BatchMode=yes lumos@172.18.21.210 true
```

启动所有设备：

```bash
cd /home/shuochen/learning/mos_fleet_monitor
./client/start-fleet-monitor.sh
./client/list-foxglove-links.sh
```

查看隧道和后台日志：

```bash
ss -ltnp | grep -E ':8765|:8766'
ls -lh "${XDG_RUNTIME_DIR:-/tmp}/mos-fleet-monitor-${UID}/"
tail -f "${XDG_RUNTIME_DIR:-/tmp}/mos-fleet-monitor-${UID}/"*.log
```

只停止 WSL 隧道：

```bash
./client/stop-fleet-monitor.sh
```

停止隧道和全部远端监控栈：

```bash
./client/stop-fleet-monitor.sh --remote
```
