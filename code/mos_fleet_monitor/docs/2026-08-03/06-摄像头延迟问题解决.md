# 摄像头延迟问题解决

## 核心说明

原始三路 RGB 直接通过 Foxglove WebSocket 传输时数据量过大，会造成帧积压。当前中继只保留最新帧，
帧龄超过 0.25 秒直接丢弃，无订阅时不编码。

```text
头部：576x324
左右臂：432x243
JPEG质量：58
帧率上限：15 FPS
```

## 全部操作代码

单独启动：

```bash
source /opt/ros/humble/setup.zsh
source /tmp/mos_all_test_ws/install/setup.zsh
export ROS_DOMAIN_ID=111
export ROS_LOCALHOST_ONLY=1

ros2 launch mos_3d_object vision.launch.py
```

另一终端：

```bash
source /opt/ros/humble/setup.zsh
source /tmp/mos_all_test_ws/install/setup.zsh
export ROS_DOMAIN_ID=111
export ROS_LOCALHOST_ONLY=1

python3 /root/work_space/mos_fleet_monitor/assets/foxglove_image_relay.py \
  --ros-args \
  -p jpeg_quality:=58 \
  -p max_fps:=15.0 \
  -p max_frame_age:=0.25 \
  -p head_width:=576 -p head_height:=324 \
  -p arm_width:=432 -p arm_height:=243
```

检查：

```bash
timeout 15 ros2 topic hz /foxglove/head_camera/image/compressed
timeout 15 ros2 topic hz /foxglove/left_arm_camera/image/compressed
timeout 15 ros2 topic hz /foxglove/right_arm_camera/image/compressed
```

Foxglove 只选择：

```text
/foxglove/head_camera/image/compressed
/foxglove/left_arm_camera/image/compressed
/foxglove/right_arm_camera/image/compressed
```
