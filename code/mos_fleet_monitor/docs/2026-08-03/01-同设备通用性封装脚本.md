# 同设备通用性封装脚本

## 核心说明

将 Vision、FAST-LIO/Nav2、压缩图像、设备状态和 Foxglove Bridge 封装为统一启停包。包内不携带
地图、ScanContext、GICP 参数或厂商 SLAM 程序。

```text
WSL源码：/home/shuochen/learning/mos_fleet_monitor
宿主机：/home/lumos/mos_fleet_monitor
容器：/root/work_space/mos_fleet_monitor
```

## 全部操作代码

生成迁移包：

```bash
cd /home/shuochen/learning/mos_fleet_monitor
chmod +x build-package.sh install_on_robot.sh client/*.sh \
  optional_vision_guard/*.sh optional_nav_guard/*.sh
./build-package.sh
```

复制到新机器：

```bash
scp dist/mos_fleet_monitor-1.2.1.tar.gz \
  lumos@<ROBOT_IP>:/home/lumos/
ssh lumos@<ROBOT_IP>
```

在机器人宿主机部署：

```bash
mkdir -p /home/lumos/mos_monitor_packages/v1.2.1
tar -xzf /home/lumos/mos_fleet_monitor-1.2.1.tar.gz \
  -C /home/lumos/mos_monitor_packages/v1.2.1
cd /home/lumos/mos_monitor_packages/v1.2.1/mos_fleet_monitor

./install_on_robot.sh --check-only
./install_on_robot.sh --with-guards
```

启停和查询：

```bash
/home/lumos/mos_fleet_monitor/bin/mos-monitor-start
/home/lumos/mos_fleet_monitor/bin/mos-monitor-status
/home/lumos/mos_fleet_monitor/bin/mos-monitor-stop
```
