# 电池电量估计

## 核心说明

当前尚未确认 MOS 对外提供可靠的 BMS 电量、电压、电流或 `sensor_msgs/msg/BatteryState` 数据。
在没有真实数据源时不发布虚假电量。

## 全部检查代码

```bash
source /opt/ros/humble/setup.zsh
source /tmp/mos_all_test_ws/install/setup.zsh
export ROS_DOMAIN_ID=111
export ROS_LOCALHOST_ONLY=1

ros2 topic list -t | grep -Ei \
  'battery|bms|power|voltage|current|charge'

find /sys/class/power_supply \
  -maxdepth 2 -type f -print 2>/dev/null
```

如果发现 `BatteryState` 话题：

```bash
ros2 topic info <BATTERY_TOPIC> -v
ros2 topic echo <BATTERY_TOPIC> --once
```

如果没有 BMS 接口，后续只能通过真机标定建立“预计剩余运行时间”，不将其宣称为真实电量。

## 任务描述

确认可靠的电池数据源；如果底层不开放，则通过真机续航标定估计剩余可运行时间。

## 进展说明

已完成可用数据源的只读检查方法整理；当前未确认真实 BMS 接口，续航标定和估计脚本尚未开发。
