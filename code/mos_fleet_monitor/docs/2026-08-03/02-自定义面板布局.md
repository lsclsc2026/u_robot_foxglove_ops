# 自定义面板布局

## 核心说明

固定 MOS 运维面板中的 3D、三路图像、ROS 日志、`status_log` 和 Diagnostics 布局。各机器人使用
同一话题名，因此切换数据源时可直接复用布局。

## 全部操作

1. Foxglove 布局菜单 → 重命名为 `MOS运维标准布局`。
2. 选择“保存更改”。
3. 选择“导出”，保存为 `MOS运维标准布局.json`。
4. 将文件放入：

```text
/home/shuochen/learning/mos_fleet_monitor/layouts/
```

将 Foxglove URL 中的 `layoutId` 写入：

```bash
nano /home/shuochen/learning/mos_fleet_monitor/client/fleet.env
```

```bash
FOXGLOVE_LAYOUT_ID="xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
```

生成固定布局入口：

```bash
cd /home/shuochen/learning/mos_fleet_monitor
./client/list-foxglove-links.sh
```

其他账号/浏览器：布局菜单 → “从文件导入” → 选择 JSON。

## 任务描述

将当前 Foxglove 运维界面固化为可导出、可分发、可跨机器人复用的标准布局。
