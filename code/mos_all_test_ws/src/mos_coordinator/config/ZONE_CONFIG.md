# 区域配置说明

## 参数定义

### 机器人ID
- `robot_id`: 机器人标识符（`"R1"` 或 `"R2"`）

### 交界区定义

交界区是两个机器人交换小车的区域，分为"满"和"空"两个子区域。

#### 1. 交界区总范围 (`boundary_zone`)
定义整个交界区的边界，包含"满"和"空"两个子区域。

```yaml
boundary_zone:
  x_min: -1.0  # 交界区左边界
  x_max: 1.0   # 交界区右边界
  y_min: -1.0  # 交界区下边界
  y_max: 1.0   # 交界区上边界
```

#### 2. 交界区"满"区域 (`boundary_full_zone`)
R2 从这里拿满车送往处理室的区域。
R1 将满车放到这里。

```yaml
boundary_full_zone:
  x_min: -1.0
  x_max: 0.0   # 左半边
  y_min: -1.0
  y_max: 1.0
```

#### 3. 交界区"空"区域 (`boundary_empty_zone`)
R1 从这里拿空车回到原位的区域。
R2 将处理后的空车放到这里。

```yaml
boundary_empty_zone:
  x_min: 0.0   # 右半边
  x_max: 1.0
  y_min: -1.0
  y_max: 1.0
```

## 逻辑规则

### R1 行为
1. **非交界区**：检测到小车 → 装载检测 → 满了就拿走送到交界区"满"
2. **交界区"满"**：跳过（留给R2）
3. **交界区"空"**：直接拿走，送回小车原位

### R2 行为
1. **非交界区**：检测到小车 → 装载检测 → 满了就拿走送到处理室
2. **交界区"满"**：直接拿走，送到处理室
3. **交界区"空"**：跳过（留给R1）

## 配置示例

### 场景1：左右分区
```yaml
# 左边是"满"，右边是"空"
boundary_full_zone:
  x_min: -1.0
  x_max: 0.0
boundary_empty_zone:
  x_min: 0.0
  x_max: 1.0
```

### 场景2：前后分区
```yaml
# 前面是"满"，后面是"空"
boundary_full_zone:
  y_min: 0.0
  y_max: 1.0
boundary_empty_zone:
  y_min: -1.0
  y_max: 0.0
```

## 注意事项

1. 所有坐标都在 **map 坐标系** 下定义
2. "满"和"空"区域不应重叠
3. 两个子区域应完全在总交界区范围内
4. 根据实际场地布局调整坐标值
